# Basemaps

Both files are from [Natural Earth](https://www.naturalearthdata.com/) (public domain) and are used only for the README maps.

- `countries.geojson`: 1:50m admin-0 countries (v5.1.2), clipped to Iberia and Fennoscandia and simplified (0.01°).
- `spain_provinces.geojson`: 1:10m admin-1 provinces of mainland Spain and the Balearic Islands, in ETRS89 / UTM 30N, as used in iberian-pines-ifn-validation.
